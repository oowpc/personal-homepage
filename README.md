# 个人主页

这是一个用于课程大作业的静态个人主页，使用 HTML + CSS 编写，可直接部署到 GitHub Pages。

## 文件说明

- `index.html`：个人主页，包含简介、学习方向、项目记录和博客入口。
- `blog.html`：第一篇技术博客。
- `styles.css`：全站样式和响应式布局。
- `assets/hero-study.png`：主页视觉图。

## 本地预览

直接用浏览器打开 `index.html` 即可预览。

## GitHub Pages 部署

1. 在 GitHub 创建一个新仓库，例如 `personal-homepage`。
2. 上传本目录中的 `index.html`、`blog.html`、`styles.css` 和 `assets/`。
3. 打开仓库 `Settings` -> `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`，保存。
6. 等待 GitHub 生成访问链接。

提交作业前，请将网页中的姓名、专业、学习方向、项目记录和联系方式替换为你的真实信息。
